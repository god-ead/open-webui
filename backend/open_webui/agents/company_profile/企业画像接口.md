# 企业画像接口文档

## 与前端交互方式

1. 任务处理完，主动发送结果，并且失败3次重试。
2. 如果前端长期没有收到信息，可能是任务发送失败，会轮询查询任务的状态，作为补充。

## 输入接口：

| 项目               | 内容                                                |
| :--------------- | :------------------------------------------------ |
| **接口名称**         | 生成目标企业画像                                          |
| **请求方法**         | `POST`                                            |
| **接口地址**         | `http://ip:port/api/task` |
| **Content-Type** | `application/json`                                |
| **接口描述**         | 对目标企业自动搜索相关信息并整理总结其企业画像，以markdown格式返回该企业画像          |


### request body（请求体）

| 参数名                | 类型     | 必填 | 说明                   |
| :----------------- | :----- | :- | :------------------- |
| `task_type` | string | 是  | 任务类型，现在默认是“profile”|
| `input` | object | 是  | 任务信息 |
| `callback` | string | 是  | 回调地址 |

### data 字段结构

| 参数名                | 类型     | 必填 | 说明                   |
| :----------------- | :----- | :- | :------------------- |
| `company_name` | string | 是  | 公司全称，如 `可孚医疗科技股份有限公司` |

### 请求示例
~~~ json
curl -X POST "http://ip:port/api/task" \
  -H "Content-Type: application/json" \
  -d '{
     "task_type" : "profile",
     "callback": "http://172.19.82.187:9090/cmi/CompanyProfile/callback" ,
     "input" : {
    "company_name" : "可孚医疗科技股份有限公司",
   }
  }'
~~~

### 输入响应

~~~ json
{"task_id":"6226c1dc-9858-4d1b-8b03-f3410f14be1c","status":"queued","queue_position":1,"created_at":"2026-05-28T21:26:39.343616"}
~~~

| 参数名      | 类型             | 必填 | 说明                      |
| :------- | :------------- | :- | :---------------------- |
| `task_id`    | string | 是  | 任务id     |
| `status` | string | 是  | 状态信息 |
| `queue_position`  | int | 是  | redis队列位置    |
| `created_at`  | string | 是 | 创建时间      |

### status取值说明

| 取值      | 含义 | 
| :------- | :------------- | 
| `queued`    | 排队中 | 
| `processing` | 处理中 |
| `completed`  | 完成 |
| `failed`  | 失败 |

## 输出接口：


### response body (响应参数)

| 参数名       | 类型      | 描述                                                         |
| :-------- | :------ | :--------------------------------------------------------- |
| `task_id`    | string | 任务id |
| `status` | string  | 状态信息                            |
| `input`    | object  | 接受信息             |
| `output`    | object  | 返回信息                 |
| `error_msg`    | string  | 错误日志                   |
| `worker_id`    | string  | 业务服务名称                 |
| `processing_time`    | float  | 处理时间                  |
| `created_at`    | string  | 任务创建时间 |                   
| `completed_at`    | stringject  | 任务完成时间  |

### output对象结构

| 参数名       | 类型      | 描述                                                         |
| :-------- | :------ | :--------------------------------------------------------- |
| `code`    | integer | 业务状态码。0表示请求处理成功，其他如下表所示。 |
| `message` | string  | 对当前 `code` 的可读性描述。                            |
| timestamp |	long	 | 服务器时间戳（毫秒）      |
| `data`    | object  | 成功时返回的企业画像数据。其结构见下方 `ProfileData` 定义。 |

### ProfileData 对象结构（data结构）

| 参数名                       | 类型             | 描述                             |
| :------------------------ | :------------- | :----------------------------- |
| `profile`                 | string         | Markdown 格式的企业画像。                 |
| `version`                 | string         | 接口或数据处理逻辑的版本号。                 |

### code具体取值说明

| code | 说明 |
| --- | --- |
| 0 | 生成该公司企业画像成功 |
| 1 | 大模型调用异常 |
| 2 |  调用失败 |

示例：

~~~ json
{
  "task_id": "6226c1dc-9858-4d1b-8b03-f3410f14be1c",
  "status": "completed",
  "input": {
    "company_name": "可孚医疗科技股份有限公司",
  },
  "output": {
    "code": 0,
    "data": {
      "profile" : "", # pdf文件下载链接
      "version" : "V0.1"
    },
    "message": "生成该公司企业画像成功",
    "timestamp": 1780020687141
  },
  "error_msg": null,
  "worker_id": "service-a-1",
  "processing_time": 303.798,
  "created_at": "2026-05-29T10:11:27.141428",
  "completed_at": "2026-05-29T10:16:30.939256"
}
~~~


## 轮询查询：

~~~ json
curl http://ip:port/api/status/task_id
~~~

参数结构与上述一致。

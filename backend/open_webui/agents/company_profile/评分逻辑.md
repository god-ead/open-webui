# 企业客户价值评分逻辑说明

> 版本：v4.0 | 满分：100分 | 配置文件：`scoring_config.yaml`

---

## 一、总体架构

系统对每家企业进行五个维度的评分，加权求和得到 0-100 的综合分，再映射到成单可能性等级。

| 维度 | 权重 | 满分 |
| ---- | ---: | ---: |
| 企业基础属性 | 40% | 40分 |
| 业务关联特征 | 20% | 20分 |
| 公开行为特征 | 15% | 15分 |
| 决策链特征   | 15% | 15分 |
| 版权风险敏感度 | 10% | 10分 |

### 成单可能性等级

| 等级 | 分数区间 | 标签 |
| ---- | -------- | ---- |
| S级 | ≥ 80分 | 高（S级客户） |
| A级 | 60–79分 | 中高（A级客户） |
| B级 | 40–59分 | 中（B级客户） |
| C级 | < 40分 | 低（C级客户） |

---

## 二、维度详解

---

### 维度1：企业基础属性（40分）

> 核心逻辑：上市/国企/外资/集团是最强信号，直接决定预算规模和合规意识。

#### 特征1：上市/国企/外资背景（满分12分）

| 值 | 含义 | 得分 |
| -- | ---- | ---: |
| listed | 上市公司（A股/港股/美股） | 12 |
| soe | 央企/大型国企 | 11 |
| foreign | 外资/合资企业 | 10 |
| group | 集团化民营 | 7 |
| private | 普通民营 | 3 |
| sme | 中小民营 | 1 |
| 数据缺失 | 默认值 | 3 |

**数据来源**：`business_info.company_type`、`business_info.name`、`governance_info.governance_type`、`overseas_info.is_foreign_invested`

**提取逻辑**（`basic_attr.py`）：
1. 优先读取 `governance_info.governance_type` 中的 `foreign` 标记
2. 扫描公司名称和类型中的关键词：上市/A股/港股 → listed；央企/国企/国有 → soe；外资/合资 → foreign；集团/控股 → group
3. 若无关键词，根据员工规模推断：>1000人 → group；<50人 → sme

---

#### 特征2：行业类型（满分10分）

| 值 | 行业 | 得分 |
| -- | ---- | ---: |
| consumer_internet | 消费/互联网/电商 | 10 |
| media_game | 文化传媒/游戏/广告 | 9 |
| finance | 金融/证券/保险 | 8 |
| pharma_retail | 医药/大健康/零售连锁 | 7 |
| premium_consumer | 高端消费品（酒/奢侈品） | 7 |
| education_tech | 教育/科技/软件 | 6 |
| manufacturing_brand | 有品牌的制造业 | 4 |
| heavy_industry | 传统重工业/农业/基建 | 2 |
| 数据缺失 | 默认值 | 4 |

**数据来源**：`business_info.industry`、`business_info.main_business`、`business_info.name`

**提取逻辑**（`basic_attr.py`）：对行业描述和公司名称做关键词匹配，按优先级顺序命中第一个类别。

---

#### 特征3：年营收（满分8分）

| 条件 | 得分 |
| ---- | ---: |
| ≥ 100亿元 | 8 |
| ≥ 10亿元 | 6 |
| ≥ 1亿元 | 4 |
| ≥ 1000万元 | 2 |
| < 1000万元 | 1 |
| 数据缺失 | 3 |

**数据来源**：`financial_info.estimated_revenue`（优先），`business_info.annual_revenue`（备用）

**提取逻辑**（`basic_attr.py`）：支持数字直接解析，也支持中文格式（如"5亿"、"3000万"）转换为元。

---

#### 特征4：总部地域（满分5分）

| 条件 | 得分 |
| ---- | ---: |
| 北京/上海/广州/深圳 | 5 |
| 杭州/成都/南京/武汉/重庆/苏州/西安/长沙/天津/宁波/合肥/郑州 | 4 |
| 其他城市 | 2 |
| 数据缺失 | 2 |

**数据来源**：`business_info.region`、`business_info.address`

---

#### 特征5：员工规模（满分5分）

| 条件 | 得分 |
| ---- | ---: |
| > 5000人 | 5 |
| > 500人 | 4 |
| 50–500人 | 2 |
| 10–49人 | 1 |
| < 10人 | 0 |
| 数据缺失 | 2 |

**数据来源**：`business_info.employee_scale`

**提取逻辑**（`basic_attr.py`）：支持"1000人以上"、"500-999人"、"50人以下"等多种文本格式解析。

---

### 维度2：业务关联特征（20分）

> 核心逻辑：字体使用需求越强（B2C、有品牌、有设计团队），成单概率越高。

#### 特征1：业务模式（满分6分）

| 值 | 含义 | 得分 |
| -- | ---- | ---: |
| b2c | 直面消费者（持续获客需求） | 6 |
| b2b2c | 间接面向消费者 | 5 |
| b2b_brand | B2B但有强品牌需求 | 4 |
| b2b | 纯B2B，品牌需求弱 | 2 |
| g2b | 政府/公共事业 | 1 |
| 数据缺失 | 默认值 | 3 |

**数据来源**：`business_info.business_model`（Kimi直接提取），或从行业/电商平台推断

**提取逻辑**（`business_rel.py`）：优先读取 Kimi 提取的 `business_model` 字段；若无，则通过行业关键词和电商平台数量推断。

---

#### 特征2：设计类岗位数量（满分5分）

| 条件 | 得分 |
| ---- | ---: |
| ≥ 5个在招设计岗位 | 5 |
| 3–4个 | 4 |
| 1–2个 | 2 |
| 0个 | 0 |
| 数据缺失 | 2 |

**数据来源**：`recruitment_info.positions`

**提取逻辑**（`business_rel.py`）：遍历招聘岗位列表，匹配关键词：设计/美工/UI/UX/视觉/创意/平面/品牌设计。

---

#### 特征3：品牌/市场部门（满分5分）

| 值 | 含义 | 得分 |
| -- | ---- | ---: |
| explicit | 有明确品牌/市场部门 | 5 |
| related | 有相关岗位但无独立部门 | 3 |
| none | 无 | 0 |
| 数据缺失 | 默认值 | 2 |

**数据来源**：`business_info.departments`、`recruitment_info.departments`、`recruitment_info.positions`

**提取逻辑**（`business_rel.py`）：先查部门列表，再查岗位列表，匹配关键词：品牌/市场/设计部/创意/营销。

---

#### 特征4：内容产出密度（满分4分）

| 值 | 含义 | 得分 |
| -- | ---- | ---: |
| high | 高频（日更） | 4 |
| medium | 中频（周更） | 2 |
| low | 低频 | 1 |
| none | 无 | 0 |
| 数据缺失 | 默认值 | 1 |

**数据来源**：`business_info.content_output_density`（直接），或从 `market_activity.ad_activity_level`、`social_media_activity`、`marketing_events` 推断

---

### 维度3：公开行为特征（15分）

> 核心逻辑：广告投放、社媒运营、电商入驻越活跃，字体使用场景越多，侵权风险越高，购买意愿越强。

#### 特征1：广告投放活跃度（满分5分）

| 值 | 含义 | 得分 |
| -- | ---- | ---: |
| multi_platform | 多平台投放（≥2个） | 5 |
| single_platform | 单平台投放 | 3 |
| none | 无投放记录 | 0 |
| 数据缺失 | 默认值 | 1 |

**数据来源**：`market_activity.ad_platforms`（列表长度判断）

---

#### 特征2：社交媒体活跃度（满分4分）

| 条件 | 得分 |
| ---- | ---: |
| ≥ 3个平台活跃 | 4 |
| 1–2个平台 | 2 |
| 0个 | 0 |
| 数据缺失 | 默认值 | 1 |

**数据来源**：`market_activity.social_media_accounts`（列表长度）

---

#### 特征3：近期营销事件（满分3分）

| 值 | 含义 | 得分 |
| -- | ---- | ---: |
| major | 品牌升级/新品发布 | 3 |
| regular | 常规营销活动 | 2 |
| none | 无 | 0 |
| 数据缺失 | 默认值 | 1 |

**数据来源**：`market_activity.marketing_events`（列表内容判断）

---

#### 特征4：电商平台入驻（满分3分）

| 条件 | 得分 |
| ---- | ---: |
| ≥ 3个平台 | 3 |
| 1–2个平台 | 2 |
| 0个 | 0 |
| 数据缺失 | 默认值 | 1 |

**数据来源**：`market_activity.ecommerce_platforms`（列表长度）

---

### 维度4：决策链特征（15分）

> 核心逻辑：大企业决策链长但预算充足，是更优质的客户；小企业决策快但预算有限。

#### 特征1：治理结构（满分5分）

| 值 | 含义 | 得分 |
| -- | ---- | ---: |
| foreign | 外资/合资（合规意识强） | 5 |
| group_subsidiary | 集团子公司 | 4 |
| joint_stock | 股份有限公司（含上市） | 4 |
| limited | 有限责任公司 | 2 |
| private_small | 小型私营 | 1 |
| individual | 个体工商户 | 0 |
| 数据缺失 | 默认值 | 2 |

**数据来源**：`governance_info.governance_structure`（直接），或从 `business_info.company_type` 关键词推断（外资/合资/集团/股份有限/有限责任）

---

#### 特征2：决策链长度（满分5分）

| 值 | 含义 | 得分 |
| -- | ---- | ---: |
| long | 长链（大集团，预算充足） | 5 |
| medium | 中链 | 3 |
| short | 短链（小公司，预算有限） | 1 |
| 数据缺失 | 默认值 | 3 |

**数据来源**：由治理结构 + 员工规模共同推断（`decision_chain.py`）

**推断规则**：
- foreign/group_subsidiary + 员工>50 → long
- joint_stock + 员工>500 → long
- individual/private_small → short
- limited + 员工>500 → long；员工50-500 → medium；员工<50 → short

---

#### 特征3：采购制度（满分3分）

| 值 | 得分 |
| -- | ---: |
| true（有集中采购制度） | 3 |
| false（无） | 1 |
| 数据缺失 | 1 |

**数据来源**：`governance_info.has_procurement_system`

---

#### 特征4：合规意识（满分2分）

| 值 | 得分 |
| -- | ---: |
| high（外资/上市公司） | 2 |
| normal（其他） | 1 |
| 数据缺失 | 1 |

**数据来源**：`governance_info.compliance_awareness`，或从 `business_info.company_type` 中"外资"/"上市"关键词推断

> 核心逻辑：有字体侵权记录的企业是最强购买信号，但大多数企业无记录，该维度权重较低。

#### 特征1：字体侵权诉讼记录（满分5分）

| 值 | 得分 |
| -- | ---: |

| false（无） | 0 |
| 数据缺失 | 0 |

**数据来源**：`litigation_info.font_infringement`

---

#### 特征2：其他知识产权诉讼（满分2分）

| 条件 | 得分 |
| ---- | ---: |
| ≥ 3起 | 2 |
| 1–2起 | 1 |
| 0起 | 0 |
| 数据缺失 | 0 |

**数据来源**：`litigation_info.ip_litigation_count`

---

#### 特征3：关联企业侵权记录（满分2分）

| 值 | 得分 |
| -- | ---: |
| true（有） | 2 |
| false（无） | 0 |
| 数据缺失 | 0 |

**数据来源**：`litigation_info.related_companies`（遍历关联公司的诉讼数量）

---

#### 特征4：行业侵权高发期（满分1分）

| 值 | 含义 | 得分 |
| -- | ---- | ---: |
| active_promotion | 正在大规模推广 | 1 |

## 三、数据流向总览

```
Kimi 联网搜索（一次 API 调用）
        ↓
  RawCompanyData（原始数据）
  ├── business_info      → 基础属性提取器、业务关联提取器
  ├── financial_info     → 基础属性提取器（年营收）
  ├── recruitment_info   → 业务关联提取器（设计岗位、部门）
  ├── market_activity    → 公开行为提取器、版权风险提取器
  ├── litigation_info    → 版权风险提取器
  ├── governance_info    → 决策链提取器、基础属性提取器
  └── overseas_info      → 基础属性提取器（外资判断）
        ↓
  五个维度特征值
        ↓
  scoring_config.yaml 规则匹配
        ↓
  综合得分（0-100）+ 成单等级 + 跟进建议
```

---

## 四、缺失数据处理

当 Kimi 未能提取某字段时，使用 `default_score` 作为该特征的得分，避免因数据缺失导致分数过低。各特征的默认分均设置为中等偏低水平，不奖励也不过度惩罚。

## 五、评分示例

**顶级客户（目标 >80分）**：上市公司 + 消费互联网行业 + 北上广深 + 多平台广告投放 + 有品牌部门

**较好客户（目标 >50分）**：集团民营 + 医药/零售/教育行业 + 新一线城市 + 有设计岗位

**较差客户（目标 <30分）**：中小民营 + 传统重工业/农业 + 三四线城市 + 无品牌投入 + 无设计需求

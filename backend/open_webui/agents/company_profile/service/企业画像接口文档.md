# 企业画像接口文档

## 与前端交互方式

1. 任务成功处理完成后主动发送结果。单个任务最多发送 3 次，首次发送包含在内。
2. 如果前端长期没有收到信息，可能是任务发送失败，会轮询查询任务的状态，作为补充。

## 输入接口：

| 项目               | 内容                                                |
| :--------------- | :------------------------------------------------ |
| **接口名称**         | 生成目标企业画像                                          |
| **请求方法**         | `POST`                                            |
| **接口地址**         | `http://ip:port/api/task` |
| **Content-Type** | `application/json`                                |
| **接口描述**         | 对目标企业自动搜索相关信息并整理总结其企业画像，默认生成 PDF 文件并返回下载链接          |


### request body（请求体）

| 参数名                | 类型     | 必填 | 说明                   |
| :----------------- | :----- | :- | :------------------- |
| `task_type` | string | 是  | 任务类型。仅支持 `"profile"`。传入不支持的类型将返回 HTTP 400 |
| `input` | object | 是  | 任务信息 |
| `callback` | string | 是  | 回调地址 |

### data 字段结构

| 参数名                | 类型     | 必填 | 说明                   |
| :----------------- | :----- | :- | :------------------- |
| `company_name` | string | 是  | 公司全称，如 `可孚医疗科技股份有限公司` |

### 请求示例
~~~ json
curl -X POST "http://ip:port/api/task" \
  -H "Content-Type: application/json" \
  -d '{
     "task_type" : "profile",
     "callback": "http://172.19.82.187:9090/cmi/CompanyProfile/callback" ,
     "input" : {
    "company_name" : "可孚医疗科技股份有限公司"
   }
  }'
~~~

### 输入响应

~~~ json
{"task_id":"77686774-b327-41ce-9554-848ff0cdc01c","status":"queued","queue_position":1,"created_at":"2026-06-26T12:51:27.315279"}
~~~

| 参数名      | 类型             | 必填 | 说明                      |
| :------- | :------------- | :- | :---------------------- |
| `task_id`    | string | 是  | 任务id     |
| `status` | string | 是  | 状态信息 |
| `queue_position`  | int | 是  | redis队列位置    |
| `created_at`  | string | 是 | 创建时间      |

### 输入错误响应

当 `task_type` 不为 `"profile"` 时，API Gateway 直接返回 HTTP 400，任务不会进入队列：

~~~ json
// HTTP 400 Bad Request
{"detail": "不支持的任务类型: profile2。支持的类型: profile"}
~~~

### status取值说明

| 取值      | 含义 | 
| :------- | :------------- | 
| `queued`    | 排队中 | 
| `processing` | 处理中 |
| `completed`  | 完成 |
| `failed`  | 失败 |

## 输出接口：

任务完成后，`output.data.profile` 默认返回 PDF 文件下载链接。调用方需要在 24 小时内下载；超过有效期后下载接口不再提供该文件。


### response body (响应参数)

| 参数名       | 类型      | 描述                                                         |
| :-------- | :------ | :--------------------------------------------------------- |
| `task_id`    | string | 任务id |
| `task_type`    | string | 任务类型 |
| `input`    | object  | 接受信息             |
| `status` | string  | 状态信息                            |
| `output`    | object  | 返回信息                 |
| `error_msg`    | string  | 错误日志                   |
| `worker_id`    | string  | 业务服务名称                 |
| `processing_time`    | float  | 处理时间                  |
| `created_at`    | string  | 任务创建时间 |
| `started_at`    | string  | 任务开始时间 |
| `completed_at`    | string  | 任务完成时间  |

### output对象结构

| 参数名       | 类型      | 描述                                                         |
| :-------- | :------ | :--------------------------------------------------------- |
| `code`    | integer | 业务状态码。0表示请求处理成功，其他如下表所示。 |
| `message` | string  | 对当前 `code` 的可读性描述。                            |
| timestamp |	string	 | 服务器时间，格式为 `yyyyMMddHHmmss` |
| `data`    | object  | 成功时返回的企业画像数据。其结构见下方 `ProfileData` 定义。 |

### ProfileData 对象结构（data结构）

| 参数名                       | 类型             | 描述                             |
| :------------------------ | :------------- | :----------------------------- |
| `profile`                 | string         | PDF 文件下载链接，默认格式为 `http://ip:port/api/download/{file}`，链接有效期 24 小时。                 |
| `version`                 | string         | 接口或数据处理逻辑的版本号。                 |

### code具体取值说明

| code | 说明 | `output.message` 格式 |
| --- | --- | --- |
| 0 | 生成该公司企业画像成功 | `success` |
| 1 | 大模型调用异常（LLM API 网络错误、超时、服务端错误导致全部采集轮次失败） | `大模型调用异常: {具体错误}` |
| 2 | 调用失败（配置缺失、企业不存在、输入无效、不支持的任务类型等业务层错误） | `调用失败: {具体错误}` |
| 3 | 企业画像生成失败（任务超时等异常）。`output.data.profile` 为空字符串，`error_msg` 保留具体异常 | `企业画像生成失败: {具体错误}` |

示例：

~~~ json
{
  "task_id": "77686774-b327-41ce-9554-848ff0cdc01c",
  "task_type": "profile",
  "input": {
    "company_name": "可孚医疗科技股份有限公司"
  },
  "status": "completed",
  "output": {
    "code": 0,
    "data": {
      "profile": "http://ip:port/api/download/77686774-b327-41_20260626_205358_8b1d4cab.pdf",
      "version": "4.0"
    },
    "message": "success",
    "timestamp": "20260626205358"
  },
  "error_msg": null,
  "worker_id": "service-1",
  "queue_position": 1,
  "processing_time": 150.919,
  "created_at": "2026-06-26 20:51:27",
  "started_at": "2026-06-26 20:51:27",
  "completed_at": "2026-06-26 20:53:58"
}
~~~


## PDF 下载：

~~~ bash
curl -L "http://ip:port/api/download/77686774-b327-41_20260626_205358_8b1d4cab.pdf"
~~~

### 下载接口返回说明

| HTTP 状态码 | 说明 |
| --- | --- |
| 200 | 文件存在且未超过 24 小时有效期，返回 PDF 文件 |
| 404 | 文件不存在，或文件名非法 |

## 轮询查询：

~~~ json
curl http://ip:port/api/status/task_id
~~~

参数结构与上述一致。
